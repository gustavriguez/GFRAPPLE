Gustavo Portfolio V22 Weather Sprite Fix

Upload site.js and styles.css to the ROOT of your Portfolio repo and overwrite the existing copies.

This patch embeds the complete 8-condition / 4-frame weather sprite atlas directly inside site.js. There is NO weather-sprites folder to upload, so the mascot cannot break from a missing GitHub path.

Weather states: sunny, partly cloudy, windy, rain, thunder, hot, night, presenter fallback.

Everything else in the site is left alone.
