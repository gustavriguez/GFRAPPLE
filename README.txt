GUSTAVO RODRIGUEZ PORTFOLIO — FLAT GITHUB PAGES BUILD

This build matches the current /GFR/ repository layout: HTML, CSS, JavaScript, images, and PDFs all live in the same folder.

UPLOAD
- Upload/replace the entire contents of this folder in the root of GFR.
- Do not create an assets/ subfolder for this build.

OWNER EDITOR
- A small “edit” link appears on the portfolio pages.
- You can also press Ctrl/Cmd + Shift + E from any page.
- The editor can change Projects, Work, Experience, Assets, project galleries, About/site copy, and weekly media.
- Project galleries accept images, local MP4/WebM paths, and YouTube/YouTube Shorts URLs.
- “Save in browser” stores changes only in that browser.
- To publish permanent changes on GitHub, use the download buttons in the editor and replace the matching files in GFR:
  - portfolio-content.js = Projects / Work / Assets
  - project-media.js = project photo/video galleries
  - site-data.js = About/status/headshot/weekly picks

ADDING A NEW LOCAL IMAGE OR VIDEO
1. Upload the media file into the same GFR folder on GitHub.
2. Open the editor.
3. In Galleries or Assets, enter the exact filename, including capitalization and extension.
4. Save locally to test it.
5. Download the updated data file and replace it on GitHub.
