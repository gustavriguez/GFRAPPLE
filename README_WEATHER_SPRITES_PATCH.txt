Gustavo Portfolio V21 — animated Tampa weather sprites

Upload these items to the ROOT of the Portfolio branch:
- site.js (overwrite)
- styles.css (overwrite)
- weather-sprites/ (new folder)

The weather sprite changes automatically from live Open-Meteo Tampa data:
- sunny
- partly-cloudy
- windy (13+ mph)
- rain / showers
- thunderstorm
- hot (feels >= 90 F or temp >= 91 F)
- night (before sunrise / after sunset)
- presenter fallback

The animated WebP is used normally. Static PNG is used when the visitor prefers reduced motion.
No HTML, media data, project data, or galleries are replaced by this patch.
